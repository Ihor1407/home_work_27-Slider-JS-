# home_work_27-Slider-JS-
## Функціонал проєкту (Features)

У цьому проєкті реалізовано сучасний та інтерактивний слайдер із наступними можливостями:

* **Динамічна навігація:** Зміна слайдів уперед та назад за допомогою кнопок управління.
* **Автоматичне перегортання:** Слайди змінюються самостійно із заданим інтервалом часу.
* **Інтерактивна пауза:** Можливість зупинити та відновити автопрокрутку кліком на відповідну кнопку.
* **Пагінація (індикатори):** Відображення поточного слайду з можливістю швидкого переходу до конкретної позиції.
* **Керування з клавіатури:** Підтримка клавіш-стрілок (Вліво / Вправо) для зручної навігації.
* **Touch & Drag (Свайпи та миша):** Повна підтримка тач-жестів для мобільних пристроїв та перетягування (drag-and-drop) мишею на десктопах.

## Projektfunktionen (Features)

In diesem Projekt wurde ein moderner und interaktiver Slider mit folgenden Funktionen implementiert:

* **Dynamische Navigation:** Wechseln der Slides vor und zurück über Steuerungstasten.
* **Automatisches Blättern:** Automatischer Wechsel der Slides in einem festgelegten Zeitintervall.
* **Interaktive Pause:** Möglichkeit, das automatische Blättern durch Klick auf eine entsprechende Taste anzuhalten und fortzusetzen.
* **Paginierung (Indikatoren):** Anzeige des aktuellen Slides mit der Option, schnell zu einer bestimmten Position zu springen.
* **Tastatursteuerung:** Unterstützung der Pfeiltasten (Links / Rechts) für eine komfortable Navigation.
* **Touch & Drag (Swipen und Maus):** Vollständige Unterstützung von Touch-Gesten für mobile Geräte sowie Drag-and-Drop mit der Maus auf Desktop-Geräten, sodass Benutzer ganz einfach durch Swipen oder Ziehen durch die Slides blättern können.
